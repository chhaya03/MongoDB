# MongoDB
<h1>Connecting node with MongoDB </h1>
To connect MongoDB with a Node.js application using Express, you can use the popular Mongoose ODM (Object Data Modeling) library.

<h2>mongoose:</h2>
Mongoose is an ODM (Object Data Modeling) library for MongoDB and Node.js. It simplifies working with
<h3>MongoDB by providing:</h3>
<ul>
 <li>Schema-based data models</li>
 <li>Validation and middleware</li>
 <li>CRUD methods (e.g., find, save, update)</li>
<li>Easy relationships and population of data</li>
</ul>


<h2>nodemon:</h2>
Nodemon is a development tool that automatically restarts your Node.js server when file changes are detected.
<ul>
 <li>Saves time during development (no need to restart server manually).</li>
 <li>Typically installed as a dev dependency.</li>
</ul>



<h1>What is MongoDB?</h1>
MongoDB is a NoSQL database — it's used to store and manage data, just like MySQL or PostgreSQL, but with a different approach.

<h2>🧠 Think of it like this:</h2>
Instead of storing data in tables with rows and columns (like SQL databases),<br>
MongoDB stores data in collections with documents that look like JSON objects.


<h2>🛠️ Tools:</h2>
MongoDB = the database<br>
Mongoose = a popular Node.js library to interact with MongoDB easily

<h2>🔄 Relationship with Node.js:</h2>
You can use Node.js + Express.js for the server, and MongoDB to store your data.
